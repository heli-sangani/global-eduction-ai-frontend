# GlobalEdu AI - Frontend Demo

## Files
- `index.html` — page structure and forms
- `style.css` — responsive styling
- `script.js` — demo interactions and sample data

## Run
1. Download and extract the ZIP.
2. Open `index.html` in a browser (Chrome, Safari, or Firefox).
3. Register with a name, email, and password, then explore the modules.

## Included modules
1. Student Registration & Login
2. University & Course Information (search and filters)
3. Student Eligibility Checker
4. University Recommendation (simple rule-based matching)
5. Online Admission Application
6. Application Status Tracking

## Important
This is a frontend-only college project demo. It uses browser `localStorage` and sample university data. Login is not secure authentication, applications are not sent to real universities, and eligibility is not an official admission decision. Connect it to the Python FastAPI backend and MySQL database for a real full-stack system.
